# Aura — Setup Guide

How to get the codebase running. This guide is split into **what runs today**
(verified) and **the full app setup** (the forward path once the UI shell is
scaffolded). Nothing here is aspirational unless labelled so.

---

## 1. Prerequisites

| Tool | Version | Needed for |
|---|---|---|
| Node.js | 18 LTS or 20 LTS | Everything |
| npm (or pnpm/yarn) | 9+ | Package install |
| Git | any | Clone |
| **For the full RN app (Phase 0 UI onward):** | | |
| Xcode | 15+ (macOS) | iOS simulator / device builds |
| Android Studio | Hedgehog+ | Android emulator |
| Expo CLI | via `npx expo` | Dev server, EAS builds |
| Watchman | latest (macOS) | File watching |

You do **not** need Xcode, Android Studio, or a simulator to run and verify the
core logic — see §3.

## 2. Get the code

```bash
unzip aura-app.zip        # or: git clone <your-repo>
cd aura-app
npm install
```

`npm install` pulls the small set of deps the logic layers need
(`zustand`, plus `tsx`/`typescript`/`react` for running tests). No native
toolchain required for this step.

## 5. Run the app on a device / simulator

> **Status:** the Expo project is now scaffolded — `app.json`, `babel.config.js`,
> the expo-router `app/` tree, and all deps are in place. Today and Closet are
> live screens; Discover/You are placeholders; the orb raises the generator
> (next build). Type-checks clean under `--strict` (`npm run typecheck`), with
> only `expo-router`/`expo-status-bar` resolving at install time.

### 5.1 Install and start

```bash
cd aura-app
npm install
npx expo start
```

Then press **i** (iOS simulator), **a** (Android emulator), or scan the QR with
**Expo Go** on your phone.

### 5.2 Expo Go vs. a dev build

- **Expo Go** works out of the box for all the UI. `react-native-mmkv` needs a
  native build, but `src/data/persist.ts` detects its absence and falls back to
  in-memory storage — so the app runs in Go, just without persistence across
  reloads.
- **Persistence** (and the production storage path) needs a dev build:
  ```bash
  npx expo run:ios       # or: npx expo run:android
  ```

### 5.3 What you'll see

1. Today opens in its empty state ("Aura needs 5 items").
2. Tap **Try a demo closet** → 20 items load; Today generates a real outfit from
   them with a reason, and the Rail fills with your wardrobe's colours.
3. **Wearing this** logs a wear (streak ticks, toast with Undo).
4. **More looks for today** swaps the drop.
5. The **Closet** tab shows the grid, filters, and the "needs tags" dot.
6. The **orb** raises a toast (generator sheet is the next build).

### 5.4 Fonts

The app boots on system fonts. To enable Aura's real type, follow
`assets/fonts/README.md` (drop three free .ttf files in and enable one block).

### 5.5 Backend (Phase 4 — not required to run)

The app runs fully offline against the local repository. When ready, add Supabase
env vars, apply `src/data/api/schema.sql`, implement the `Repo` interface against
Supabase, and switch one line. Nothing else changes.

## 7. Troubleshooting

- **`Cannot find package 'zustand'/'react'`** when running tests → `npm install`.
- **`npx expo start` errors about a missing app dir** → the UI shell isn't
  scaffolded yet; see §5.1. The tests in §3 are what runs today.
- **MMKV crash in Expo Go** → expected; MMKV needs a dev build. The in-memory
  fallback keeps early UI work runnable in Go.
- **Reanimated "plugin" error** → add the babel plugin (§5.2) and clear the
  cache: `npx expo start -c`.
